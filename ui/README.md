# COZY COFFEE

React 주문 화면입니다. 메뉴별 옵션을 선택해 장바구니에 담고, 수량과 주문 금액을 확인할 수 있습니다. 같은 메뉴와 옵션 조합을 다시 담으면 수량이 증가합니다. 주문을 제출하면 접수 안내와 함께 장바구니가 비워집니다.

화면 요구사항은 [주문하기 화면 PRD](../docs/PRD.md)를 참고하세요.

## 개발 서버 실행

```bash
npm install
npm run dev
```

## 검증

```bash
npm run lint
npm run build
```

현재 메뉴 데이터와 주문 접수는 화면 동작을 확인하기 위한 프런트엔드 예시이며, 서버 API에는 연결되어 있지 않습니다.
